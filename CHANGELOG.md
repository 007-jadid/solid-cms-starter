# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2025-01-01

### Added

- SolidJS 1.9 with TanStack Router, Query, Table, Form, and Virtual
- 80+ UI components built on Kobalte and Corvu primitives
- Tailwind CSS v4 with oklch design tokens, dark mode, and theme variants
- Config-driven form system with 25+ field types, multi-step wizards, array fields, and Valibot validation
- Advanced data table with sorting, filtering, pagination, inline editing, row selection, drag-and-drop, virtualization, sub-grids, bulk actions, and CSV/Excel export
- Authentication with JWT token management, automatic refresh, and route guards
- Role-based access control (RBAC) with component guards, route guards, and action filtering
- Internationalization (i18n) with English and Bengali locales
- Chart.js integration with 6 chart types (area, bar, line, pie, doughnut, radial)
- Map system with Leaflet and Google Maps providers, location search, and drawing tools
- Rich text editor (Quill v2) with build-time feature toggle
- Media picker dialog for file uploads
- PWA support with service worker and offline caching
- Real-time features: WebSocket and SSE contexts
- Notification center with web push support
- GSAP animation directives (fade, scroll reveal, stagger, count-up, hover lift)
- Glass-morphism design system with presets
- Onboarding modal for first-time users
- Command palette for entity search
- Settings page with theme, density, font, and sidebar preferences
- Stat card and audit log components for dashboards
- User profile page
- Bundle analysis with rollup-plugin-visualizer
- Vitest + Testing Library test infrastructure
- Biome + ESLint linting with SolidJS-specific rules
- Vite 7 with advanced code splitting and build-time feature toggles
